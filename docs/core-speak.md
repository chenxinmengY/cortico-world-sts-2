# 直连气泡：希望宿主提供的一条发言通道

本 World 的闲话（"这波厉害不？""疼死我了"）默认走**世界直连桌宠气泡**：不经过模型、不花 token、延迟低于 0.3 秒。

要做到这一点，宿主（Coopanion / Cortico）需要提供一条**不唤醒模型**的发言口子。本文说明这条口子的形状、没有它时的行为，以及为什么值得加。

> 这是本插件对宿主的一个**接口需求**，不是补丁说明。接口签名由本插件提出，实现方式由宿主决定。

## 需要的两个可选方法

宿主的 `WorldHost` 上加两个**可选成员**即可（没有也不影响其他 World）：

```ts
export interface WorldHost {
  // …宿主已有的成员…

  /**
   * 让当前注册的发言人直接开口。
   * 不进 session、不唤醒模型、不产生工具回执。
   * 没有发言人、对方没连上、或宿主判定这句话已过期时返回 false，调用方自行决定是否回退。
   */
  speak?(text: string, opts?: { source?: string; ttlMs?: number }): boolean;

  /**
   * 发言人 World 注册自己（桌宠的气泡就是这个通道）。
   * 同一时刻只保留一个发言人，后注册的替换先注册的。
   * 返回注销函数；宿主已失效时调用无效果。
   */
  registerSpeaker?(fn: (text: string, opts?: { source?: string; ttlMs?: number }) => boolean): () => void;
}
```

要点：

| 约定 | 为什么 |
|---|---|
| 两个方法都可选 | 老版本宿主不实现也能加载本 World |
| `speak` 返回 `boolean` | 气泡没弹出来（对方离线、页面没连）时，调用方要知道并回退 |
| 同一时刻只有一个发言人 | 多个 World 抢着说话会打架；后注册者胜出，简单可预期 |
| `ttlMs` 由宿主判定过期 | 一句"疼"压在队列里 10 秒再说出来就是噪音 |
| 不产生事件、不进历史 | 这是本条通道的全部价值：它不占上下文 |

## 没有这条通道时

本 World 自动降级，**功能不缺失**：

1. 先探测 `host.speak` 是否存在；
2. 不存在就退回 `sts-2.murmur` 事件，由模型复述成气泡；
3. 代价是慢 2–4 秒、每次一条额外模型调用，台词还会进对话历史。

`chatterDelivery` 配置项就是这条降级路径的显式开关：

- `direct`（默认）：优先直连，没有通道时自动退回 `murmur`；
- `model`：直接从 `murmur` 走，不尝试直连。

## 为什么值得加

闲话是高频、低信息量的内容。走模型时，一句 30 字的台词会：

- 触发一次完整模型调用（哪怕只是复述）；
- 在之后每一轮请求里被重发一遍；
- 出现在对话记录里，干扰玩家回看。

直连通道把这三项全部归零。对宿主来说，这只是把"桌宠已经有的气泡能力"开放成一个方法，不需要新的子系统。

## 宿主自己实现时的注意事项

- 对方没连上时**返回 false**，不要静默吞掉——否则插件无法回退。
- 不要让 `speak` 触发任何工具回执或事件，否则等于绕了一圈又回到模型。
- 多个 World 注册时按"后注册胜出"，并在注销时恢复上一个（或干脆只保留一个）。
- 句子长度不限，但建议宿主侧对超长文本做截断，气泡不是滚动条。
