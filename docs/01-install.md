# 01 · 安装

目标：**20 分钟内看到她在打牌**。全程不需要改代码。

## 你要准备的四样东西

| # | 东西 | 怎么拿 | 检查点 |
|---|---|---|---|
| 1 | 《杀戮尖塔 2》 | Steam 买，抢先体验版即可（实测 `0.111.0`） | 能正常开局 |
| 2 | **RitsuLib 0.6.0+** | 创意工坊搜 `RitsuLib` | 订阅即可，它是别的 mod 的前置 |
| 3 | **NekoSpire**（猫娘尖塔） | 创意工坊 ID `3794941932` | 进游戏后能在 mod 列表里看到 |
| 4 | **Coopanion / Cortico 0.2.x** | 你已经在用的那个桌宠应用 | 版本 ≥ 0.2.5（World 契约 6） |

> NekoSpire 只是"桥"——它把游戏状态变成一段 JSON 放在本机端口上，再把动作送回去。
> **不需要装 NEKO 客户端**，装 mod 就够。

---

## 第 1 步：确认桥活着

先只做这一件事，别急着装插件。

1. 启动游戏，**进入一局**（主菜单的桥是半死状态，不要在这时候判断）。
2. 打开 PowerShell，敲：

```powershell
curl.exe http://127.0.0.1:18080/health
```

**你应该看到**：一段类似 `{"ok":true,"data":{"status":"ready",...}}` 的 JSON。

看到 `ok:true` → 桥通了，继续第 2 步。

看不到 / 报连接失败 → 先解决这里：

| 现象 | 原因 | 处理 |
|---|---|---|
| `无法连接到远程服务器` | mod 没加载 | 游戏里按 mod 菜单确认 NekoSpire 在列表里且启用；缺 RitsuLib 时它不会加载 |
| 端口能连但 `status` 不是 `ready` | 还在主菜单 | 进一局再看 |
| 端口冲突 | 你改过端口 | 游戏的 mod 配置里看 `STS2_API_PORT`；插件里也要改成一样的 |

> 桥只监听 `127.0.0.1`，不对外网开放。这是刻意的。

## 第 2 步：把插件注册成 Coopanion 的扩展

> **市场里搜不到？** 两个来源不一样：扩展市场读的是 npm，本仓库在发到 npm 之前，
> 市场里**搜不到属于正常**，不代表你装错了。本地安装走下面这条 `link:` 的路，功能完全一样。
> 想从市场装，等 npm 上出现 `cortico-world-sts-2` 再来。

Coopanion 用一份清单登记本地扩展。找到它：

```
<Coopanion 安装目录>\data\extensions\package.json
```

用记事本打开，在 `dependencies` 里加一行（**路径换成你自己的插件目录，斜杠用 `/`**）：

```json
{
  "name": "cortico-extensions",
  "private": true,
  "dependencies": {
    "cortico-world-sts-2": "link:D:/path/to/cortico-world-sts-2"
  }
}
```

保存。然后**完全退出 Coopanion**（托盘图标也要退），重新启动。

> `link:` 的意思是"直接指向这个文件夹"，不是复制。所以你以后更新插件只要改文件、重启宿主，
> 不用重新安装。反过来说，**别把插件目录挪走或改名**，否则宿主找不到。

如果重启后 World 列表里没有 `杀戮尖塔 2`，在 `data\extensions\` 目录里手动装一次依赖：

```powershell
cd "<Coopanion 安装目录>\data\extensions"
pnpm install
```

没有 pnpm 就先装：`npm i -g pnpm`（需要 Node ≥ 22）。

---

## 第 3 步：启用 World

打开 Coopanion 的 **World 概览**，找到 **杀戮尖塔 2**，打开开关。

**你应该看到**：

- 状态灯从灰变绿（`桥` 那一栏显示已连接）；
- 如果游戏没开，灯是红的——**这是正常的**，插件每 5 秒重连一次，游戏开起来会自己接上。

---

## 第 4 步：验收

1. 游戏里进一局，随便走两步；
2. 看桌宠有没有开始动（她会替你出牌）；
3. 想停就说一句"停"。

**成功的样子**：她打完一张牌，等半秒，再打下一张，偶尔冒一句"这波厉害不？"。

**没成功**：不要在这里猜，直接去 [06 出问题了](06-troubleshooting.md)，按症状查。

---

## 卸载

1. World 概览里关掉开关；
2. 从 `data\extensions\package.json` 里删掉那一行；
3. 重启 Coopanion。

插件不写注册表、不装服务、不改游戏文件；删掉文件夹就干净了。
