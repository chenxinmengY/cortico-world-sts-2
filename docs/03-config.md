# 03 · 配置全解

配置在**宿主**里改，不在插件文件夹里改。位置：Coopanion → 设置 → **杀戮尖塔 2** 这一组。

大部分项改完立即生效，不用重启；`connectTimeoutMs` / `savePath` / `chatterLinesFile` / `exposeObserve` / `devTools` 这几项要重启宿主。

想还原默认值：删掉那一项，或按下面的表填回去。

---

## 常见需求 → 改哪个

| 你的感受 | 改这个 | 怎么改 |
|---|---|---|
| 她话太多 | `chatter` | 设成 `off` 完全闭嘴，或把 `chatterCooldownMs` 拉长到 120000 |
| 她说话太频繁 | `chatterWinChance` / `chatterHurtChance` | 各降到 0.1；两个概率是"最多说多少"，不是"一定说" |
| 她打得太莽 | 说一句"稳一点"，或用 `solverAutoplayStopHpPct` 提前把残局交回模型 | 默认 30% 就交回 |
| 战斗太慢、每步都等模型 | `solverAutoplay` 打开 | 整场由求解器打，不叫醒模型，只在需要决策时交回 |
| 求解器把游戏拖卡 | `solverPrefetchMs` 调大，或直接关 `solver` | 它一次搜索能吃满 0.7 秒 CPU，真机上卡过 |
| 她老在主页自己开局 | `quietOnMenu` 保持 `true` | 默认就是开的 |
| 她老替你点"继续" | `autoAdvance` 关掉 | 关掉后连"结束回合"都要你自己点 |
| 卡住时她一直催 | `idleNudgeMs` 设 0 | 关掉"没动静提醒" |
| 断线一次就说话 | `connectionQuietMs` 调大 | 默认 3 秒内的抖动当没发生 |
| 多人局她抢着点地图 | `coopRouteWaitMs` 调大 | 默认等 4 秒，设 0 表示一直等队友先投 |
| 想省 token | 关 `exposeObserve`、关 `batchHint` | 关掉后她偶尔会拿旧编号试动作，谨慎 |
| 想让她自己打整场战斗 | `solverAutoplay` + `solverAutoplaySummary` | 前者开接管，后者决定打完要不要说一句 |

## 全部配置项

| 配置项 | 默认 | 说明 |
|---|---|---|
| `baseUrl` | `http://127.0.0.1:18080` | **桥地址** —— 游戏内 mod 的监听地址；默认 http://127.0.0.1:18080（mod 侧可用 STS2_API_PORT 改）。 |
| `launch` | `false` | **挂载时启动游戏** —— 用 steam://rungameid/2868840 拉起游戏。停用 World 时不会关游戏。 |
| `retryIntervalMs` | `5000` | **重连间隔** —— 没连上桥时多久重试一次；游戏开起来后会自动接上。 范围 500–120000ms。 |
| `connectTimeoutMs` | `60000` | **启动连接期限** 范围 1000–600000ms。 |
| `actionTimeoutMs` | `30000` | **动作结算期限** —— 求解器可能算到 8 秒（Deep 预算更久），留够余量。 范围 1000–180000ms。 |
| `stateTimeoutMs` | `5000` | **读状态期限** 范围 500–60000ms。 |
| `stateEventThrottleMs` | `600` | **状态事件节流** —— 两次状态推送之间的最小间隔；0 表示不限。 范围 0–10000ms。 |
| `blockedGraceMs` | `1500` | **空动作宽限** —— 桥短时间内没有动作（界面动画、结算中间态）不算卡住；超过这个时长才提醒人。 范围 0–30000ms。 |
| `pauseOnUnknownScreen` | `true` | **未知界面停手等人** —— 桥没有给出任何动作时，发一条提醒后停住，等你手动点完。 |
| `remindAtTurnEnd` | `true` | **轮末提醒** —— 她这一轮动过手、游戏仍在等输入时，补一条提醒；不动手就不提醒。 |
| `pollIntervalMs` | `1200` | **轮询间隔** —— 事件流断开时的兜底读取间隔。 范围 200–10000ms。 |
| `autoAdvance` | `true` | **没得选就替她点** —— 只剩“结束回合 / 领完继续 / 打开宝箱 / 离开商店”这类推进动作时自动执行；有取舍的屏永远停下等她。 |
| `maxRejectsBeforeStop` | `2` | **连续失败几次停手** —— 同一个局面下同一个操作被桥连续拒绝到这个次数，就停手并在面板上说一句。 范围 1–10。 |
| `idleNudgeMs` | `10000` | **没动静的提醒间隔** —— 游戏在等输入、她却一直没有动作时，先提醒一次，再一个间隔后停住。0 表示关。 范围 0–600000ms。 |
| `combatGraceMs` | `9000` | **战斗里的空动作宽限** —— 敌方回合、动画期间桥会短暂不给动作，这是正常的；等这么久还没动作才算卡住。 范围 1000–60000ms。 |
| `readSave` | `true` | **读存档判断读档** —— 读 current_run.save 里的读档次数与 seed；读不到时自动退回纯内存判定，不影响其他功能。 |
| `savePath` | `""` | **存档路径** —— 留空表示自动在 %APPDATA%/SlayTheSpire2 下找最新的 current_run.save。 |
| `driftNoticeMs` | `60000` | **“对不上”提示间隔** —— 局面和她的记忆对不上（但没到回档）时的提示最小间隔。 范围 0–3600000ms。 |
| `chatter` | `rare` | **偶尔说一句** —— 战斗结束夸一句、挨打哼一声。off 完全不说话；rare 每层偶尔一两次；normal 再活跃一些。 可选：`off` / `rare` / `normal`。 |
| `chatterDelivery` | `direct` | **闲话怎么出声** —— direct：世界直接把台词送进桌宠气泡，不进模型、不花 token；model：发 murmur 事件让模型复述（慢几秒，每次一整轮调用）。 可选：`direct` / `model`。 |
| `chatterSuffix` | `，库…` | **句尾口癖** —— 直连气泡时自动加在每句末尾（会把原来的句号换成它）；留空不加。走模型时由模型自己带口癖，这里不生效。 |
| `chatterLinesFile` | `""` | **台词文件** —— 台词池 JSON 的路径；留空用数据目录下的 chatter.json（首次启动自动写一份默认的，改完保存即生效；换路径需重启）。 |
| `chatterWinChance` | `0.35` | **打完夸一句的概率** —— 每场战斗结束时的触发概率；normal 档会再乘 1.5。调低这个或拉长下面的冷却，都能让她更安静。 范围 0–1。 |
| `chatterHurtChance` | `0.3` | **挨打说一句的概率** —— 一次掉 5 点以上血时的触发概率；normal 档会再乘 1.5。 范围 0–1。 |
| `chatterCooldownMs` | `45000` | **两句之间的最短间隔** —— 两次"偶尔一句"之间至少隔这么久，防止刷屏；直连气泡延迟很低，靠它压频率。 范围 0–600000ms。 |
| `solver` | `true` | **贴求解器建议** —— 战斗里读桥自带的求解器，把“下一步建议”作为一行注记贴进局面；只建议，不会替她出牌。 |
| `solverTimeoutMs` | `6000` | **求解器超时** —— 拿不到就当作没有这条注记，不阻塞她打牌。 范围 500–30000ms。 |
| `solverMinConfidence` | `0.6` | **求解器置信门槛** —— 低于这个置信度就不贴建议；覆盖不全或有风险时也不贴。 范围 0–1。 |
| `solverPrefetchMs` | `2000` | **求解器建议的最小间隔** —— 求解器一次搜索约 0.7 秒满载 CPU；两次要建议至少隔这么久，否则每帧一问会把游戏拖卡（真机上卡过）。观战和接管期间一律不问。 范围 0–30000ms。 |
| `solverAutoplay` | `false` | **战斗交给求解器打** —— 战斗里由桥自带的求解器一步步打完，整场不叫醒模型，只在需要决策时交回：求解器算不出、编号对不上、血太低、要结束一回合会死的回合，或者已经离开战斗。和「贴求解器建议」是两个开关：关掉注记也能让它代打。 |
| `solverAutoplayMaxSteps` | `12` | **一次接管最多几步** —— 超过这个步数就交回模型，防止求解器和桥互相顶着转圈。 范围 1–64。 |
| `solverAutoplayStopHpPct` | `30` | **低于这个血量就交回** —— 生命百分比低于它时不再替她打，把残局交给模型。 范围 1–100%。 |
| `solverAutoplaySummary` | `true` | **战斗结束后说一句** —— 每场用求解器打完的战斗结束后发一条摘要（一条事件 = 一次模型调用）。 |
| `observeThrottleMs` | `3000` | **重复观察的节流** —— 同一局面在这个间隔内被再次观察时只回一句话，不重发状态；0 表示不节流。要全量时用 detail:"full"，永远放行。 范围 0–60000ms。 |
| `exposeObserve` | `true` | **把 sts2_observe 给模型** —— 默认开：求解器交回、断线恢复时要靠它拿新状态码。关掉能省调用，但模型会拿旧状态码试动作，只在确认不需要时关。 |
| `devTools` | `false` | **排障工具** —— 把 sts2_probe 暴露给模型；正常对局用不上，开着只会多烧 token。 |
| `batchHint` | `true` | **单步后提醒批处理** —— 战斗里单步 do 之后，在回执末尾提示改用 sts2_play；不改变她实际怎么打。 |
| `quietOnMenu` | `true` | **主页不替她开局** —— 主菜单和选角色界面不推局面、不自己点「继续上次的局」「出发」，等玩家说了才动。关掉后她一看到主页就会自己接着打。 |
| `queueStateEvents` | `true` | **局面等她这一轮走完再推** —— 她还在思考时，新到的局面先合并，等这一轮结束再一起给；减少打断和多余的模型调用。 |
| `blockedRetryMs` | `4000` | **卡住后的回读间隔** —— 判定“这一屏点不动”之后，每隔这么久自己再读一次局面；接上了就继续，不用玩家出声。 范围 500–60000ms。 |
| `coopRouteWaitMs` | `4000` | **多人路线等待（0=一直等）** —— 多人局进地图后先压这么久再推给她，给队友投票的时间。0 表示一直等，直到队友先投票（队友不投她就一直不点，地图会停在那儿）；队友一投票就提前推（让她跟票，而不是当第一个点的人）；压着的时候不催她、也不推地图，到点推的是最新投票。 范围 0–30000ms。 |
| `connectionQuietMs` | `3000` | **断线多久才吭声** —— 事件流断开后，短于这个时长的抖动重连回来就当没发生（一次事件 = 一次模型调用）；只有真断了这么久才说一句，接回来再说一句。 范围 0–120000ms。 |
| `statePath` | `/state` | **状态路径** |
| `actionPath` | `/action` | **动作路径** |
| `eventPath` | `/events/stream` | **事件流路径** |
| `capturePath` | `/capture` | **截图路径** —— 桥不支持时留空即可。 |

## 关于成本的三个事实

改配置时容易忽略这三点，它们比"少说两句"影响大得多：

1. **每推一次局面 = 一次模型调用。** 所以 `stateEventThrottleMs`（默认 600ms）和 `queueStateEvents`（默认开）是省钱主力，不是 `chatter`。
2. **求解器接管期间不叫醒模型。** `solverAutoplay` 是唯一能把"一整场战斗"压缩成"零次调用"的开关，代价是打得没模型细腻。
3. **闲话默认不花钱。** `chatterDelivery: direct` 时台词直接进气泡，不进上下文；只有宿主没有直连通道时才退回 `murmur`（每次一条调用）。详见 [core-speak.md](core-speak.md)。
