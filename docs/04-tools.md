## 她每一轮看到的东西

一份**局面**，长这样（简化）：

```text
【StS2 状态码 a1b2c3d4e5f6 · 战斗 · 可操作】
P hp68/80 block5 energy3 |手牌: 打击 打击 防御 重击+| 抽5 弃3 消0
E1 腐化哨兵 hp28/40 block0 |!intent atk12| 力量2
E2 爬行怪 hp12/12 |!intent buff|
可做: 1=打击→E1 2=打击→E2 3=防御 4=重击→E1 5=结束回合
```

三个关键点：

1. **状态码**（`a1b2c3d4e5f6`）绑定这一帧。局面一变，旧码立刻作废——所以你插手不会和她打架。
2. **编号**（`1=`、`2=`）是动作入口，她只能报编号，报不了"我想打那张牌"。
3. **意图带段数**（`atk12` vs `atk12x2`），因为 12 点格挡挡不住两次。

回执只报变化，不重发全屏：

```text
HP 68→61 E3→1 | E1 28→16 | 抽牌堆 5→4
```

## 十个工具

| 工具 | 她什么时候用 | 参数 | 返回 |
|---|---|---|---|
| `sts2_do` | 执行**一个**编号动作 | `state`、`action` | 回执（结果 + 变化） |
| `sts2_play` | 战斗里一次提交**一整轮**（≤8 步） | `state`、`steps[]` | 一份回执 |
| `sts2_inspect` | 要看牌组 / 全图 / 完整局面 | `what: deck\|map\|full` | 对应文本 |
| `sts2_observe` | 断线恢复、求解器交回后拿新码 | `detail: decision\|full`（可选） | 当前局面 |
| `sts2_pause` | 停手，切到**观战模式**：不推局面、只看不动 | `reason`（可选） | — |
| `sts2_resume` | 恢复并重读局面 | — | 当前局面 |
| `sts2_steer` | 记玩家的临时指令 | `text`、`until` | — |
| `sts2_intent` | 记这一局的构筑意图 | `note` | — |
| `sts2_capture` | 要看画面（桥支持时） | — | PNG；桥没有就**明确失败** |
| `sts2_probe` | 排障（默认不给她） | — | 原始 `/state` + 归一化摘要 |

### `sts2_do` 与 `sts2_play` 怎么选

| 情况 | 用哪个 |
|---|---|
| 战斗里要打多张牌 | **`sts2_play`**（一次提交，只回一份回执，省调用） |
| 地图选路、领奖励、商店、事件 | `sts2_do`（一次一个编号） |
| 选牌屏（画面写着"选择 N 张牌"） | `sts2_play` 的 `{select:n}`，**必须一次列全** |

`{select}` 只在选牌屏用，而且同一张只能选一次；奖励、选角色、事件一律用 `sts2_do`。

### `sts2_pause` 之后她还在看

停手不是"关掉"，是**切到观战模式**——这两件事分开：

| 停了 | 没停 |
|---|---|
| 局面不推给模型（不产生调用） | 桥照读，血量和胜负她都看得见 |
| `sts2_do` / `sts2_play` 被拒：「现在是观战模式，只看不动」 | 掉血、打赢照样说话，只是切到 `watch` 那套第二人称台词 |
| 求解器接管也会一起停 | 被闲话叫醒时也不许顺手出牌 |

这个闸是写死的（`world.ts` 里对 `sts2_do` / `sts2_play` 的拦截），不是靠提示词约束——模型想说也说不动。
`sts2_resume` 才会解除，并先重读一次局面。

### `sts2_steer` 的四种有效期

| `until` | 含义 |
|---|---|
| `next` | 下一步就作废 |
| `floor` | 本层内有效（默认） |
| `screen` | 本界面内有效 |
| `manual` | 直到你再说一句覆盖它 |

传空字符串等于撤销。

## 八个事件

| 事件 | 什么时候发 | 她要做什么 |
|---|---|---|
| `sts-2.state` | 局面变了 | 看编号决定是否动手 |
| `sts-2.decision` | 她动过手，游戏仍在等 | 判断要不要继续 |
| `sts-2.blocked` | 这一屏桥没给动作（宽限 1.5 秒确认，每个状态只提醒一次） | 告诉你"这屏我点不了，你来一下" |
| `sts-2.connection` | 桥真的断了（短抖动不算） | 知道已提交动作的结果可能未确认 |
| `sts-2.rollback` | 检测到回档 / 重开 | 之前的判断全部作废，重读 |
| `sts-2.drift` | 局面和记忆对不上，但没到回档 | 以现在这份为准 |
| `sts-2.auto` | 没得选的屏她替你点了一次，或求解器打完一场的摘要 | 知悉即可 |
| `sts-2.murmur` | 一句闲话（默认直连气泡，不走这个事件） | 复述成气泡 |

> **一次事件 = 一次模型调用**（`murmur` 走直连时不调用）。这就是为什么"少推一次局面"比"少说一句话"省钱得多。

## 她不会做的事

这些是设计上的硬约束，不是没做完：

| 不做 | 原因 |
|---|---|
| 不给 `save_and_quit` / `abandon_run` 编号 | 她不该顺手把你的局退了 |
| 不注入键鼠 | 看不到的界面就停住，不用坐标硬点 |
| 不写存档 | 只读 `current_run.save` 的两个字段（读档次数、种子） |
| 不编造画面 | 桥没有 `/capture` 时 `sts2_capture` 直接失败 |
| 不重发整屏 | 没有变化就不推，靠状态码而不是靠"再读一遍" |
