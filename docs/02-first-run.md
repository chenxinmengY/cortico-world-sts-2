# 02 · 第一次运行

装好了，先搞清楚三件事：**她什么时候会动**、**怎么让她停**、**怎么插一句话**。

---

## 她什么时候会动

一句话：**局面一变，她收到一份"现状 + 编号"，然后挑一个编号动手。**

你不需要下命令，也不需要点"开始"。游戏里只要出现需要选择的东西，她就会接上。

会动的时机：

| 场景 | 她做什么 |
|---|---|
| 战斗轮到你了 | 出牌，出到打不动或没能量 |
| 走地图 | 选一条路 |
| 战斗结束发奖励 | 领奖、选牌 |
| 商店 | 买她想买的 |
| 事件 / 篝火 / 宝箱 | 选一个选项 |
| 只剩"结束回合""继续"这类按钮 | **替你点掉**，不打扰你 |

**不会动**的时机（都是刻意的）：

- 主菜单、选角色界面 —— 等你发话（`quietOnMenu`）；
- 你说过"停" —— 直到你说"继续"；
- 这一屏桥没给任何选项 —— 她会提醒你点一下，然后等你；
- 同一个操作被拒了两次 —— 停手，并在面板上说一句。

## 你会看到什么

桌宠会：

1. **隔一小会儿动一次**（不是连点，中间有结算和思考）；
2. **偶尔说话**：打完一场夸一句、挨一下重的喊声疼；
3. **你不用看聊天窗口**——她的话直接在气泡里，默认不进模型、不花钱。

如果你打开宿主里 `sts-2` 这个世界的对话页，会看到她每一轮调了什么工具。**看不懂没关系，那是给排障用的。**

## 三个最重要的操作

### 停

对她说：

> 停
> 停一下
> 别打了

她就不动了，也不再推局面。**已经提交出去的那一步不会撤回**（那一步在游戏里已经发生了）。

### 继续

> 继续
> 接着打

她会先重读一次局面，再接着打。

### 插一句话（打断）

这是这个插件和你平时用的"AI 助手"最大的区别：**你说的话不是聊天，是打断。**

| 你说 | 她的理解 |
|---|---|
| 这张别打，先防御 | 下一步照这个来 |
| 这层别碰精英 | 本层有效 |
| 这局走毒 | 整局的构筑意图（换局失效） |
| 商店别买 | 本界面有效 |

有效期分三层，都会自动过期，不需要你手动撤销：

- **下一步**：动一次就作废；
- **本层 / 本界面**：离开这层或这个界面就作废；
- **直到撤销**：你再说一句覆盖它。

她每次动手前都会看到这些要求挂在局面上，所以不会"说过就忘"。

## 她打错了怎么办

三种情况，对号入座：

| 情况 | 处理 |
|---|---|
| 打法不合你意（该防她打） | 说一句"先防御"，下一步就改；长期偏好用"这局走毒"这种意图 |
| 她**看不懂这一屏**（完全不动） | 你手动点一下，她会跟上；想帮忙就把抓包发到 issue |
| 她在**重复同一个动作** | 一般是被桥拒了；看 [06 出问题了](06-troubleshooting.md#重复同一个动作) |

## 关于读档（SL）

她**能识别回档**：读存档里的读档次数和种子，判断你是不是快速 SL 了。

- 识别到 → 她会说一句，然后**重新读局面**，之前的判断作废；
- 你打篝火回满血**不会**被误判成读档（这是专门修过的坑）；
- 读不到存档 → 退回纯内存判断，功能不受影响。

## 一句话总结

> 她自动打，你只在忍不了的时候说一句；那句就是打断。
> 想让她彻底停下，说"停"。
